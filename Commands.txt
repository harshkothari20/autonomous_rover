source /opt/ros/jazzy/setup.bash
colcon build --packages-select mars --symlink-install  
source install/setup.bash

Launching Everything including website:  ros2 launch mars mars.launch.py



* launching Gazebo   - ros2 launch mars gazebo_model.launch.py  
* launching NAV2     - ros2 launch nav2_bringup bringup_launch.py     use_sim_time:=True     map:=/home/linuxpc/ros2_ws/src/mars/maps/my_clean_room.yaml   
* RVIZ2              - ros2 run rviz2 rviz2 -d /opt/ros/jazzy/share/nav2_bringup/rviz/nav2_default_view.rviz
* Teleop             - ros2 run teleop_twist_keyboard teleop_twist_keyboard
* saving map         - ros2 run nav2_map_server map_saver_cli -f warehouse_map --ros-args -p save_map_timeout:=10.0







Debugging:
* ros2 topic list - outputs a list of all active topics currently present on the ROS 2 network that have registered publishers or subscribers. 
* ros2 topic info </topicName> - gives info about the particular topic name 
* ros2 topic echo </topicName> --field <fieldName> - prints values of that particular field
